TrustSetu

TrustSetu is a web platform designed to help users verify the authenticity of images and text online.
It aims to reduce misinformation by allowing users to upload content and check whether it is real or potentially manipulated.

🚀 Features

- Image upload and verification interface
- Text verification system
- Clean modern UI with dark mode
- Responsive design for mobile and desktop
- Secure and fast frontend built with Next.js

🛠 Tech Stack

- Next.js
- React
- Tailwind CSS
- TypeScript

📂 Project Structure

app – Main application pages
components – UI components
hooks – Custom React hooks
lib – Utility functions
public – Static assets
styles – Global styles

📌 Purpose

TrustSetu aims to create a bridge of trust on the internet by helping people verify digital information before believing or sharing it.
